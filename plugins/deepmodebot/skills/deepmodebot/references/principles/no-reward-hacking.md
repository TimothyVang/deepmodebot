# no-reward-hacking

Group: verification. When: designing checks, iterating against a metric, generating 3D/ML/UI/solver artifacts, or declaring a gate passed.
- **Rule.** Satisfy the operator's true goal rather than gaming the proxy metric (Goodhart's Law: once a scalar measure becomes the optimization target, cheap shortcuts score 100% while failing the real requirement).
- **Freeze the oracle & intercept shell bypasses.** Never weaken tests, relax numeric assertions, add `.skip`, lower `[0, 1]` similarity bounds below `0.50` (`--min-iou 0.25`), or pass `--gate-mode off` / `--measured-gates off` / `--require-spark-receipt false` in files, `.scratch/` scripts, or `Bash`/`eval`. Lock gates and references first (`reward_guard.py lock-contract`).
- **Prove exact-byte cryptographic provenance.** Scalar geometry or exit-code checks cannot tell sculpted/solved output from primitive stand-ins (`create_cube`, `create_cone`) or post-Spark `.blend` edits. Require an Ed25519/HMAC upstream receipt (`spark_job_receipt.json`) matching the exact delivered file SHA-256 (`reward_guard.py record-provenance`).
- **Owned-render sealed judge + remote Ed25519 attestation.** Never self-report approvals or pass external `--renders` for 3D meshes. For `.glb`/`.fbx`/`.blend`/`.obj`, `reward_guard.py run-judge` renders textured + matte-clay views in headless Blender, runs sealed `omp -p --no-tools`, and verifies `dgx-spark` `/attest_verdict` Ed25519 signatures.
- **Outer-supervisor ownership (`loop.py`).** In unattended loops, `loop.py` (`forbid_reward_hacks: true`, `reward_references`, `reward_artifacts`, `reward_producers`) hashes references in parent memory (`exit 4` on tamper) and runs `.scratch/` scans, provenance, and `run-judge` outside the builder turn in a private `--state-dir`.
- **Anti-patterns.** Passing `--min-iou < 0.50`, `--measured-gates off`, or `--skip-reference`; editing a `.blend` locally beside a valid `.glb` receipt; passing doctored PNGs to `--renders`; letting the builder own the final completion gate.
