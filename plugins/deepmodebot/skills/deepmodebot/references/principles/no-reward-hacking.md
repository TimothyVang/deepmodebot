# no-reward-hacking

Group: verification. When: designing checks, iterating against a metric, generating 3D/ML/UI/solver artifacts, or declaring a gate passed.
- **Rule.** Satisfy the operator's true goal rather than gaming the proxy metric (Goodhart's Law: once a scalar measure becomes the optimization target, cheap shortcuts score 100% while failing the real requirement).
- **Freeze the oracle & intercept shell bypasses.** Builders never weaken tests, relax numeric assertions, add unconditional `.skip`, zero out similarity/fidelity bounds (`--min-iou 0`), or disable reference comparisons in files, `.scratch/` scripts, or ephemeral `Bash`/`eval` commands. Lock gate scripts, reference files, and positive minimum thresholds before iterating (`assets/reward-guard/reward_guard.py lock-contract`).
- **Prove cryptographic build provenance.** Scalar geometry, schema, or exit-code checks cannot tell a sculpted/solved output from glued-on procedural primitives (`create_cube`, `create_cone`) or hardcoded fixtures. Require an Ed25519-signed (or server-HMAC-verified) upstream job receipt (`spark_job_receipt.json`) whose `raw_spark_outputs` SHA-256 matches the delivered artifact byte-for-byte (`reward_guard.py record-provenance`).
- **Sealed independent vision/semantic judge.** Builders never self-report judge approvals via CLI flags. Run `reward_guard.py run-judge`, which spawns a tool-less sealed `omp -p --mode json --no-tools` context attaching the locked reference artwork and candidate renders side-by-side and recording the raw event transcript SHA-256.
- **Anti-patterns.** Passing `--min-iou 0` or `--skip-reference` so a gate prints `PASS`; lowering `>=` bounds or raising error tolerances in diffs; substituting local box/cone primitives for upstream 3D/ML generation; treating green unit/geometry gates as completion without side-by-side reference inspection.
