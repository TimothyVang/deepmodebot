# no-reward-hacking

Group: verification. When: writing code or tests, fixing bugs, iterating against any check/benchmark/gate, building UIs/APIs/CLIs/ML/3D, or declaring work done.
- **Rule.** Satisfy the operator's true goal rather than gaming the proxy metric across **all** engineering domains (Goodhart's Law: once a test, benchmark, linter, or scalar gate becomes the optimization target, shortcuts score 100% while failing the real requirement).
- **Freeze tests, snapshots, strictness & shell flags.** Never delete/tautologize assertions (`assert True`), overwrite golden snapshots unprompted (`--update-snapshots`, `jest/vitest -u`, `cargo insta accept`), replace `package.json` scripts with `echo`/`true`/`exit 0`, run empty filters (`go test -run=^$`), add `.skip`/`xfail`/`--no-cov`/`--passWithNoTests`/`continue-on-error: true`, weaken `tsconfig`/`mypy`/`pyright`/`biome`/Rust `#![allow(warnings)]`, lower quality/latency/throughput/coverage bounds, stub `/api/` in E2E specs, fit ML models on `test`/`eval` splits, disable TLS/FK checks (`verify=False`, `PRAGMA foreign_keys = OFF`), or branch on `PYTEST_CURRENT_TEST`/`JEST_WORKER_ID` in production.
- **Universal sealed judge (`run-judge`).** On code/API/CLI/ML/perf tasks (no images or DGX required), `reward_guard.py run-judge` runs `--verify-cmd` itself, captures `git diff` + untracked files, and audits both inside a sealed `omp -p --no-tools` prosecutor signed with an outer-supervisor RFC 8032 Ed25519 key. On UI/2D/3D tasks, it attaches locked references + owned headless Blender renders (`.glb`/`.fbx`/`.blend`/`.obj`) and verifies upstream Ed25519 receipts when required.
- **Outer-supervisor & CI ownership (`loop.py` + `slop_gate.py` + `self_grill.py`).** `slop_gate.py` scans both git diffs and `.scratch/` scripts/symlinks on every `local_ci.py run`; `self_grill.py` enforces critical `no-reward-hacking` verification across test/config/eval/E2E diffs; and `loop.py` freezes protected files and guardrail configs (`exit 4` on mutation) while running `run-judge` from a private `realpath`-verified holdout.
- **Anti-patterns.** Hardcoding test fixture inputs or `PYTEST_CURRENT_TEST` branches in `src/`; overwriting snapshots (`-u`) to silence regressions; stubbing backend `/api/` routes in E2E tests; fitting on `X_test`; `verify=False` to silence TLS failures; deleting assertions; letting the builder own the final completion gate.
