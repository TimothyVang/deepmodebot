# guard-the-context-window

Group: delegation. When: context is filling or fan-out / loops risk heavy token burn and provider rate limits.
- **Rule.** Route bulk to subagents (`task`, `scout` for read-only); keep summaries and file pointers in the main thread, not raw payloads. Overflow degrades reasoning, creates compression artifacts, and burns cache/quota.
- **Indexed orientation.** Run `python -B "<deepmodebot skill>/assets/workspace-map/workspace_map.py"` (`py -3 -B` on Windows) with `overview --fast --offline --no-orca` (~300 tokens, unless already hook-injected in Antigravity) and `query <term>` for exact `path:line` pointers instead of broad directory walks or wide greps (`references/techniques/workspace-map.md`).
- **Token & cache hygiene.** Clear between unrelated tasks (`/clear` or fresh session), pass file/line paths instead of pasting diffs or logs, trim test output to 20-30 failing lines, and keep `AGENTS.md`/`CLAUDE.md` under ~200 lines with unused or eager MCP servers off. Reuse warm agents (`write agent://<id>` / `SendMessage` / `send_message`) and keep model, effort, and tools fixed mid-thread so exact-prefix prompt caches stay hot (`skill://agent-harnesses/references/delegation-efficiency.md`).
- **Rate-limit & model-switching budget.** Cap parallel spawns (3-5 per batch), skip optional multi-agent flows (`tournament`, `swarm`) when single-agent or `S`/`M` suffices (uncommitted local `S`/`M` edits need no merge `panel`, but every published PR or shared-branch landing still requires the exact-head 3-verifier, 2-of-3 `panel`), and avoid Fast/Ultrafast multipliers (2x-8x quota burn). Check headroom (`omp usage`, `/usage`, `/status`), route `S`/`M` work off flagship `L` at clean boundaries, and back off or rotate model families on 429s.
