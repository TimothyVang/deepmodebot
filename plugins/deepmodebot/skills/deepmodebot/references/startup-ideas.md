## Saved leads

- **Doctor-office administrative assistant:** [source story,08:46](https://www.youtube.com/watch?v=pnZh5PAF3VE&t=526). Anonymous, second-hand signup/pricing claims are not market validation. Start with one synthetic-data, nonclinical workflow and authorized human approval, not diagnosis or autonomous patient messaging.
- **Managed team collaboration:** [source,03:04](https://www.youtube.com/watch?v=pnZh5PAF3VE&t=184). Validate actual migration, integration and operating requirements rather than assuming a free Slack replacement has feature parity.
- **Opt-in coding-agent trace and improvement:** [source,34:19](https://www.youtube.com/watch?v=pnZh5PAF3VE&t=2059). Session/commit linkage is a reference pattern; consent, secret redaction and retention matter before collecting real traces.
- **Voice-to-prototype coaching:** [source,37:23](https://www.youtube.com/watch?v=pnZh5PAF3VE&t=2243). Test a bounded sandboxed workflow; do not inherit permission-bypass defaults from a demonstration.
- **Human-feedback media editing:** [source,38:38](https://www.youtube.com/watch?v=pnZh5PAF3VE&t=2318). Use rights-cleared media. The speaker's custom feedback tool is not established as a published repository.

## Choose before building

Name the customer, job, data sensitivity, jurisdiction, platform and acceptable license. Search the existing repository catalog by project terms; reference topics and cautions describe possible relevance, not tested suitability. Inspect current primary docs and exact license scopes, then exercise the selected candidate before adoption.

For the doctor idea, OpenMausBot's Apache-2.0 core does not cover its [enterprise directory](https://github.com/milind-soni/OpenMausBot/blob/main/enterprise/LICENSE). Enterprise production needs a key; third-party hosting, resale and white-labeling of enterprise features require a separate partner agreement. Core-only reuse must exclude enterprise code and follow applicable licenses.

No referenced repo is established as healthcare-ready. If real health data or clinical functions become part of the scope, assess the actual service chain and applicable rules; the archived brief cites HHS cloud guidance and FDA's function-specific CDS guidance. No clinical or legal classification was made by this collection.
