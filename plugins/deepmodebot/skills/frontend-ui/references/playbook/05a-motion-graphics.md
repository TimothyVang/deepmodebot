## 5a. Motion graphics and video
Scope: rendered MP4s (launch films, explainers, social clips, docs videos). **§5's 300 ms UI caps and frequency gates do not apply here.** Viewers see each beat once on a music/voice clock. The prompt is ~10% of the result; the harness (brand assets, beat grid, springs, critique loop, sound) is 90%.

1. **Render contract:** every frame is a pure function of `t` (`useCurrentFrame()` in Remotion, `seek(t)` in HyperFrames/HTML) — zero CSS transitions, timers, `rAF` accumulation, `Date.now()`, unseeded random, or unbaked physics. Render frames in parallel via headless Chrome → ffmpeg. Keep **one timeline file** (beats/sections rounded to frames at the end), name the engine explicitly, and cache every stage artifact to disk so approved assets aren't regenerated.
2. **Plan in words, then gate:** 3 storylines → numeric spec (goal, output, time, look, objects, motion, shots, **Banned**, QA) → storyboard with each shot's *reads* → beat map + ~6 stills or 1-frame/beat contact sheet **before full render**. Gates: plan → rig → stills → animatic → full pass → polish → audio → render. Re-edits must explicitly start from scratch.
3. **Director's brief skeleton:** Inputs (real product URL/2× Playwright assets, fonts, 1 accent, formats, music) · Direction (1-line film, reference grammar never content, growing Banned list) · Structure (BPM, bars, event per beat) · Build rules · Stills gate · Deliverables (MP4, loop check, poster, contact sheet, README).
4. **Video timing (budget holds first — first drafts run too fast):** entrance ~400 ms; exit ~200 ms (25–50% faster); single move `<= 600 ms`; fast move `0.3–0.6 s` with motion blur; words/items `60–120 ms` / `40–80 ms` stagger; text hold `0.3 s/word + 0.5 s` (last line `>= 2 s`); wordmark hold `>= 1 s`; pre-payoff stillness `0.3–0.75 s`; new visual beat every `2–4 s`. Landed text is **dead still**.
5. **Easing & transitions:** long-tailed arrivals (`cubic-bezier(0.16, 1, 0.3, 1)` / `expo.out`), camera `inOut`, accelerating exits; springs damping `0.7–0.85` (1.0 for product UI), never bounce opacity/color. Use 3–5 object-carried transitions (zoom through button, morph, whip, iris) matching exit/entry vectors, cut mid-motion; never crossfade worlds; hard cuts only on action/beat/layout-form change (`<= 1/3` of seams). Strong loop: **one container that never cuts**.
6. **Beat sync & sound:** at 120 BPM, 1 beat = 0.5 s, 1 bar = 2 s, scenes = 3–4 beats; fit beat grid with `librosa` (`<= 15 ms` residual) into `beats.json`; max 3 full-frame impacts; verify cut error `<= 3 frames`. Three audio layers (bed, visible-action foley, licensed/user music); master to **−14 LUFS, `<= −1 dBTP`**; SFX peaks land +1 frame after picture.
7. **Launch films & type floors:** real 2× product UI doing one real task (establish → isolate at 1.6–2× → return result); cursor 4–7% of frame firing next beat; first frame = thumbnail (never black/lone logo); end card in last 5–10% with CTA held 1.5–3 s. Type floors at 1080p: captions `>= 56 px`, secondary `>= 28–32 px`, headline `>= 84 px`, `<= 6` words/line, check at `360–480 px`; rewrite copy rather than shrinking type.
8. **Look, manifest & video forensics:** keep a reread manifest (`design.md`, `frames.md`, Banned list) + asset bank dictionary (never AI-drawn logos/icons); chain generated stills/clips from previous frame to lock theme. Before remaking a reference video, run `skill://deepmodebot/references/techniques/video-forensics.md` (`rea-video`) for cut timings/rhythm/stems and `rea-video compare`.
9. **Voice-over & shot budget:** voice-over first with word-level timestamps; keep overlays out of face-safe zone; split multi-speaker audio per track; SFX last. ~6–8 shots per 15 s (hook `< 3 s`); 1 shot per generation call; iterate on stills + 15 s proof before long cut; narrated stills ~2.5 words/s (cut silences `> 0.4 s`); explicitly forbid burned-in subtitles and constrain camera with start/end frames.
10. **Visual review (watch collectively + zoom checks):** contact sheet → consecutive-frame strips around seams → full-res text crops → full-speed viewing with sound → clean-context critic. Write timestamped P0–P2 notes (`t · where · problem → change · what stays`) and fix worst 3 per round for 3+ rounds (human watches final cut).
11. **Stack & safety:** Remotion (React/TS; free `<= 3` people) or HyperFrames (Apache-2.0), R3F + per-frame baked Rapier for 3D/physics, librosa for beats, Blender MCP for hero 3D; one motion engine per composition (`references/patterns/motion-graphics.md`). Expose tweakable timings/blur as props; deny `.env` reads, keep MCP localhost-only, disable skill telemetry.
12. **Scroll-scrubbed marketing (Persuade only) & embedded video:** drive depth/scrubbed video by scroll position (ancestors `overflow: visible`, parallax `<= 15%`, sticky runway ~2,000 px, drop sticky/horizontal scroll on phones, single poster frame under reduced motion). Product-UI video: muted autoplay only if decorative, captions on, pause control, poster under reduced motion.
