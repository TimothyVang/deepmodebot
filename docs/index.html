Read the full FAQ

Does deepmodebot need an API key?

No. It runs on your agent CLI's subscription login; prompts still reach your model provider.

How much does the plugin cost?

Nothing. It is MIT licensed; usage counts against your own plan.

Does deepmodebot work outside omp?

Yes, in Claude Code, Codex and Antigravity. Outside-contributor reviews need omp.

Can the plugin write outside my repo?

Not with the guard on. The hook skips shell commands, so the skill's rule covers bash.

Is deepmodebot faster than a plain agent?

No. In the measured fixture the plain agent used less; deepmodebot adds gates and proof.

Set up deepmodebot in omp in 4 steps

1

Add the marketplace

omp reads the plugin list straight from the GitHub repo.

$ omp plugin marketplace add TimothyVang/deepmodebot
2

Install the plugin

omp copies the skills, commands and agents into its plugin cache.

$ omp plugin install deepmodebot@deepmodebot
3

Turn on the write guard

The link file loads the guard from the plugin, so upgrades never leave a stale copy.

$ cp omp-contain-link.ts ~/.omp/agent/hooks/pre/
4

Run your first task

Type the command and the task in any repo; it picks the playbook.

> /deepmodebot:deep add retry backoff to the poller
